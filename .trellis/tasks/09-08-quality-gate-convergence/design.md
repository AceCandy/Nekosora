# 质量门禁收敛设计

沿用各包现有 `tsc --noEmit` 与 ESLint，不增加检查框架。移除 Core、Web、Queue 对测试文件的排除；Core 对历史 schema 别名的解析与现有 Vitest 一致。类型诊断在对应测试中修复：优先补充准确夹具、修正过时调用和合法类型收窄。刻意测试无效输入时，仅在输入边界明确表达该意图。

各现有 lint 脚本加入 `--max-warnings 0`。保留当前规则等级，清理实际警告，不增加禁用注释。生产代码仅移除未使用的类型 import，其他运行时行为保持不变。

同步特性/shared 说明及前后端目录、质量规范，明确 `apps/worker`、`packages/contracts/queue` 和现有别名归属。后端质量规范的空模板用本批验证过的门禁替换。

回滚以本批配置、测试与文档差异为边界，无数据迁移。测试进入 Web 的类型检查不代表进入应用路由或运行时 bundle；构建仍依照 Next 的既有入口。
