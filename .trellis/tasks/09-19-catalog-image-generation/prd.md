# 手动维护模型图像生成能力

## 需求

管理员可以在 Web 模型模板预览中开启或关闭图像生成能力。模板可同时支持聊天和绘图，手动标记不被 pi 同步覆盖。

## 验收

- 复用 model_catalog.capabilities.imageGeneration，不新增字段或能力副本，不改变 modelType。
- 仅管理员可修改；提示立即生效、影响所有引用该模板的模型、pi 同步保留标记以及上游接口兼容限制。
- 更新只修改目标 JSON 属性，保留并发更新的其他能力；失败可见并可重试。
- 绘图入口按能力筛选，聊天类型兼容；同步回归覆盖开启与关闭。
- 不自动开启任何模型，不修改已有迁移。
- 完成权限、持久化、UI、筛选与同步测试，并执行质量检查和独立复核。

## 扩展：Responses 绘图（已获用户授权）

- 管理员可以选择 Images 或 Responses 出图方式；旧记录仍走 Images。
- Responses 使用所选聊天模型调用内置 image_generation 工具，解析 PNG/base64，保留现有路由、鉴权、超时、用量记录和图片存储。
- Responses 单次仅生成一张；前后端共同限制数量与 SDK 支持的尺寸，不暗中拆分付费请求。
- 出图方式存入目录 capabilities，pi 同步保留；不按模型名称猜测协议。
- 不扩展聊天内工具交互、图片编辑、Gemini、任务队列或画布。
