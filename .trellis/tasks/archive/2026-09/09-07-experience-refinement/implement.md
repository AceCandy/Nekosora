# 实施与验证

保存即生效：先改共享事务及并发契约，再接通全部设置 action/生产读取/保存文案，最后改按需历史和确认撤销。验证无变化、旧 revision、无效引用、事务写入失败、旧草稿隔离、历史不可变及撤销冲突；独立复核后运行类型、lint、单元及可安全执行的隔离 PostgreSQL 测试。

1. 模型选择与输入器：键盘/目录档位测试，桌面和手机布局验证。
2. 接入与导航：复用现有页面动作，验证高级字段保留和权限空态。
3. 用量和视觉文案：URL 筛选不变，校准统计范围，检查双语。
4. 独立复核 diff，运行 lint/typecheck/相关测试，浏览器复测，清理调试产物。

主代理实施，遵守项目子代理仅探索/核验的约束。

反馈修正验证：先用 changes.test.ts 复现清理不存在旧字段的错误，再修共享 merge；补离散滑杆映射和原生顶层/焦点时序测试；浏览器复核预览、Escape、模板搜索、问号帮助及聊天导航。真实 PostgreSQL 集成仅允许安全脚本的 localhost 隔离库，不绕过环境限制。
