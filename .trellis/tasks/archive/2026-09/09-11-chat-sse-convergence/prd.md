# 聊天 SSE 消费流程收敛

## Goal

四种生成动作共享同一处 SSE 事件和终态处理，降低后续修改遗漏风险。

## Requirements

- 扩展已有共享事件投影，统一正文/思考、错误追加、assistant 标识、元数据与终态回填。
- 保留发送、重新生成、编辑重发、续写各自请求体、预检/回滚、版本选择及标题/附件回调。
- 保留增量先 flush 再错误、错误帧后协议异常不重复报错、续写前缀和多会话隔离。
- 复用现有 SSE parser 与 Store 测试，不引入新状态机、依赖或通用请求框架。

## Acceptance Criteria

- [x] 四个动作仅通过一个 Store 消费函数调用 parser；测试覆盖共同终态和各动作差异。
- [x] 新回归在重构前后通过，原有测试不削弱。
- [x] 全量质量门禁和受影响应用构建通过，独立复核和剩余风险已记录。
