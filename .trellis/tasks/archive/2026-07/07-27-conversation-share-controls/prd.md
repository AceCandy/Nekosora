# 网盘式对话分享

## Goal

把对话分享升级为可配置、可撤销的网盘式流程。创建者可选择分享模式、有效期、输出样式和可选访问密码；访问者在权限允许时看到与 Chat 默认消息外观一致的只读 Markdown 对话。

## Background

- 当前分享入口会立即创建链接并复制，没有配置步骤；`src/features/chat/components/ChatHeader.tsx` 也没有历史链接或撤销入口。
- `src/db/schema/pg.ts` 的 `conversation_shares` 只有标题、模型、消息快照和状态字段，没有模式、到期时间、密码验证值或样式快照。
- `src/features/chat/actions/share.ts` 当前读取快照时仍按实时软删除状态过滤，不是严格冻结；公开页 `src/app/share/[shareId]/page.tsx` 直接输出纯文本，没有复用 Chat Markdown 渲染。
- 同一会话允许创建多个链接；后端已有 `revokeShare`，但没有生产 UI 调用。
- 当前消息版本切换只更新浏览器内存，刷新后回到最新版本。实时分享若要跟随创建者的版本选择，必须让 Chat 与分享读取同一份持久化选择状态。
- 输出样式是管理员维护的全局预设；仅保存样式 ID 无法防止快照随预设修改、禁用或删除而漂移。
- 项目现有 SHA-256 helper 用于高熵 API Key，不适合低熵访问密码；现有缓存接口也不提供多实例原子限流。

## Requirements

### 创建与管理

- 点击分享先打开配置界面，取消时不得创建记录。
- 配置项包含分享模式、有效期、输出样式和可选访问密码；密码长度为 8 至 128 个字符。
- 有效期提供“1 天”“7 天”“30 天”“永久”和“自定义日期时间”。自定义值按创建者本地时区选择，服务端保存绝对时间，且必须晚于创建时刻。
- 分享记录创建后不可修改模式、有效期、密码或输出样式；变更只能撤销旧链接并重新创建。
- 配置界面列出当前会话的全部分享，展示模式、创建时间、有效期和状态，并提供复制与撤销；不返回密码哈希或解锁信息。

### 分享模式

- 实时同步分享在每次访问时读取会话当前标题、模型、可见消息版本和输出样式。
- 实时同步跟随后续编辑、消息软删除、版本切换、样式切换和新增消息；创建界面必须明确提示未来新增内容也会持续公开。
- 实时同步强制跟随会话当前输出样式，不允许为链接单独固定样式。
- 快照分享冻结创建时的标题、模型、可见消息顺序与正文，以及创建者选择的完整输出样式语义；后续消息或预设变化不得改变新建快照。
- 快照可选择任一当前已启用样式，默认使用会话当前样式。冻结内容至少包含稳定 CSS 类、CSS 内容和渲染器类型，不能只保存样式 ID。
- 删除整个会话时，分享链接沿用现有级联失效行为；本期的严格快照保证针对消息、版本和输出样式变化。

### 访问控制

- 永久分享没有到期时间；其他分享在服务端按绝对时间判断到期。
- 密码只保存带随机盐和成本参数的慢哈希验证值，不得保存或记录明文，也不得进入 URL、客户端持久化数据或日志。
- 密码校验必须在服务端完成，并按分享与客户端来源实施原子失败计数和临时限流。
- 解锁状态只绑定单个分享，在当前浏览器记住 24 小时或至分享链接到期，以较早者为准；分享撤销或到期后立即失效。
- 不存在、撤销、过期和尚未解锁的分享不得泄露标题、模型、消息正文或输出样式内容。

### 展示与兼容

- 公开页复用 Chat 默认用户消息外观、助手正文布局和 Markdown/自定义渲染链路。
- 公开页不显示编辑、删除、重生成、版本切换、反馈等登录态操作。
- 旧分享无需回填即可继续访问，保持旧版快照删除语义，并按永不过期、无密码、默认输出样式兼容。
- 新增或修改的界面文案必须进入现有国际化资源。

## Acceptance Criteria

- [ ] 分享按钮打开配置界面；取消不会写入记录，创建成功后展示并可靠复制唯一链接。
- [ ] 可选择实时同步或快照，并在创建实时分享前看到“未来新增内容也会公开”的明确警告。
- [ ] 有效期可选择 1 天、7 天、30 天、永久或未来的自定义日期时间；跨时区访问仍在同一绝对时刻失效。
- [ ] 实时同步不能选择独立样式，并在后续访问时反映当前标题、模型、消息编辑/删除、持久化版本选择、样式变化和新增消息。
- [ ] 快照默认使用当前会话样式，也可选择任一启用样式；创建后消息顺序、正文和样式不受会话或预设修改、禁用、删除影响。
- [ ] 已创建分享不能编辑配置；当前会话分享列表可查看状态、复制链接和撤销任一链接。
- [ ] 无密码且可用的分享可直接访问；受保护分享在解锁前只显示密码表单，不返回任何私密元数据。
- [ ] 错误密码有统一反馈并受原子频率限制；正确密码只解锁当前分享 24 小时或至链接到期，以较早者为准。
- [ ] 过期、撤销和不存在的链接显示统一不可用状态，且不能通过响应差异获得分享内容。
- [ ] 公开消息视觉与 Chat 默认外观一致；Markdown、代码块、表格和已支持的自定义渲染可正常静态展示，且没有聊天操作控件。
- [ ] 旧分享按原有可见内容继续访问，视为永不过期、无密码和默认样式。
- [ ] PostgreSQL migration、Drizzle journal/snapshot、相关单元/组件测试、lint 和类型检查全部通过。

## Out of Scope

- 分享内容协作编辑、评论或下载打包。
- 匿名访问者账户体系。
- 跨会话的全局分享管理页面、批量撤销与筛选分页。
- 已打开实时分享页的 WebSocket/SSE 推送；“实时”指每次访问或刷新读取最新持久化状态。
- 改变删除整个会话时分享链接级联失效的既有行为。
- 将公开链接作为搜索引擎可索引内容。
- 生产 CDN、短域名或外部对象存储配置。
