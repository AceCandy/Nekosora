# Chat 文本选中浮工具栏

## Goal

用户选中消息内文本时，在选区附近浮出工具栏，提供复制 / 引用插入输入框 / 追问三个快捷操作。

## Requirements

- 在 assistant 或 user 消息正文中选中文本后，选区上方/下方浮出小工具栏
- 三个操作：
  - **复制**：复制选中文本到剪贴板
  - **引用**：将选中文本以引用格式插入输入框（聚焦输入框，光标定位）
  - **追问**：以选中文本为新问题继续当前会话（直接发送，不走分支）
- 选区消失（点击别处）时工具栏消失
- 工具栏定位跟随选区（getBoundingClientRect）
- 移动端：长按选中后同样浮出（或降级为系统菜单后的二次入口——design 阶段确认）

## Acceptance Criteria

- [ ] 消息文本选中后浮出工具栏
- [ ] 复制可用
- [ ] 引用插入输入框且输入框聚焦
- [ ] 追问能以选中文本发送并得到回复
- [ ] 点击别处工具栏消失
- [ ] 滚动时工具栏跟随或隐藏（不残留）
- [ ] 暗色模式正常

## Constraints

- 仅在消息正文区生效，不在输入框/侧栏误触发
- 与虚拟滚动（chat-virtual-scroll）联动：虚拟化后选区定位需重算，该适配由 virtual-scroll 子任务回头处理
- 不阻塞浏览器原生选中/复制
