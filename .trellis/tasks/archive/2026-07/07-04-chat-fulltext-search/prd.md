# Chat 全文搜索

## Goal

侧栏搜索从「仅标题」升级为「按消息内容全文搜索」，跨所有会话，命中可跳转。属前后端联动架构级任务。

## Requirements

- 侧栏搜索框支持按消息内容搜索（不只标题）
- 后端新增搜索 API：输入关键词，返回命中会话 + 命中消息片段（snippet）+ 高亮
- 前端搜索结果分组展示：按会话聚合，每条显示会话标题 + 命中片段预览
- 点击命中项跳转到对应会话对应消息（scrollIntoView）
- 权限：只搜索当前用户自己的会话
- 搜索范围：所有会话（含已归档？design 阶段确认）
- 性能：design 阶段在 LIKE 与 FTS5 之间选择（消息表规模决定）

## Acceptance Criteria

- [ ] 搜索关键词能命中消息正文（不只标题）
- [ ] 结果按会话聚合，显示命中片段
- [ ] 点击结果跳转到对应会话并定位消息
- [ ] 只返回当前用户的会话
- [ ] 搜索响应在可接受范围（design 阶段定阈值）
- [ ] 现有标题搜索不被破坏（作为全文搜索的子集）

## Constraints

- 后端搜索接口需鉴权（better-auth session）
- FTS5 需建虚拟表 + 触发器同步，或退化为 LIKE（design 阶段权衡）
- 高亮片段需做 HTML 转义防 XSS
- 搜索框防抖（避免每键一次都请求）
