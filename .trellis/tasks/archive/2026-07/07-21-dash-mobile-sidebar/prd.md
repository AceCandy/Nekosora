# 后台侧边栏移动端抽屉适配

## Goal

让 `/panel` 与 `/admin`（包括 `/admin/settings`）在手机和窄屏设备上使用标准的侧栏抽屉导航，避免固定侧栏长期占用正文宽度；桌面端继续保留现有图标栏折叠能力。

## Background

- 当前后台侧栏由 `AppShell.tsx` 与 `DashSidebar.tsx` 共享，移动端仍固定占用 `w-56`。
- 当前折叠按钮使用 `hidden md:inline-flex`，折叠宽度也只配置 `md:w-14`，因此小于 `768px` 时既不能收起，也没有独立的导航入口。
- 聊天侧栏已有移动端遮罩抽屉模式，可复用其交互约定，但后台壳保持自身导航和桌面折叠状态。

## Requirements

1. 小于 `md` 的视口使用移动端顶栏与左侧模态抽屉：默认关闭，顶栏菜单按钮打开，侧栏关闭按钮、遮罩点击和 `Escape` 均可关闭。
2. 移动端抽屉打开时锁定页面滚动，将焦点移入抽屉并限制键盘焦点不越出；关闭后焦点返回菜单按钮。
3. 点击品牌、导航项或底部链接后关闭移动端抽屉；登出行为继续使用现有 server action。
4. `md` 及以上维持现有侧栏展开/图标栏折叠行为，状态仍为会话内 `useState`，不新增持久化。
5. 菜单、关闭、展开和收起标签接入 `next-intl`，不新增硬编码中文 UI 文案。
6. 保持现有设计 token、暗色模式、reduced-motion 兜底和 `touch-target` 触控目标约定。
7. 同步更新前端组件规范中关于后台移动端侧栏的契约。

## Acceptance Criteria

- [x] `320px` 与 `390px` 视口下，正文不被固定侧栏挤占，顶栏菜单按钮可见且可打开抽屉。
- [x] 移动端抽屉可通过关闭按钮、遮罩、`Escape`、品牌/导航/底部链接关闭。
- [x] 抽屉打开时背景页面不可滚动；键盘 `Tab` / `Shift+Tab` 焦点保持在抽屉内，关闭后回到菜单按钮。
- [x] 移动端菜单与关闭按钮在粗指针环境下点击区域不小于 `44x44px`，页面无横向溢出。
- [x] `768px` 与 `1280px` 视口下，现有桌面侧栏及 `w-14` 折叠行为不回归。
- [x] 亮色、暗色下顶栏、遮罩、抽屉边界和焦点状态可辨识。
- [x] 中英文环境下菜单、关闭、展开、收起均有正确的可访问名称。
- [x] `pnpm lint` 与 `pnpm typecheck` 通过；组件规范与实现一致。

## Out of Scope

- 不修改聊天侧栏交互。
- 不新增侧栏状态持久化、手势滑动关闭或底部导航。
- 不调整后台导航信息架构、路由、权限和数据逻辑。
