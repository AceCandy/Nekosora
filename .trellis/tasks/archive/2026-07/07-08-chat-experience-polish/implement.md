# 执行计划 · 聊天体验打磨

按子项顺序推进，每个子项独立改动、可独立验证、可独立回滚。

## 1. 空闲态停止多余轮询
- 改动：侧栏组件 `Sidebar`。引入 `useRouter`；派生 `hasGenerating`；轮询 effect 以 `hasGenerating` 为开关；后台会话完成或本轮无 generating 时 `router.refresh()` 同步。
- 验证：空闲态（无 generating 会话）浏览器网络面板不再有 6 秒周期请求；存在后台生成会话时仍轮询且完成后给蓝点。

## 2. 流式中保留历史消息复制 / 版本按钮
- 改动：消息项组件 `ChatMessageItem`。操作栏容器条件改为 `!(isStreaming && isLast)`；重新生成 / 续写 两块各加 `!isStreaming`；复制按钮与版本切换始终保留。
- 验证：会话流式中，历史 assistant 消息显示复制 + 版本切换（不显示重新生成 / 续写）；正在生成的最末条无操作栏；非流式时所有按钮恢复。

## 3. 回到最新按钮按需展示
- 改动：滚动控制器 `useChatScrollController` 新增宽阈值 `isNearBottom`（距底 ≤ 1/3 视口高），跟随窄阈值 `isAtBottom`（< 24px）不变；消息变化跟随 effect 中 rAF 重算并同步两者。消息列表 `ChatMessageList` 按钮条件由 `!isAtBottom` 改为 `!isNearBottom`。
- 验证：距底 ≤ 1/3 屏时按钮隐藏（视为在最新附近）；上滑超过 1/3 屏才显示；跟随行为不变（上滑 > 24px 即停跟随）。流式结束后按钮正确隐藏。

## 4. 流式生成下方留白
- 改动：消息列表组件 `ChatMessageList`。流式时底部缓冲由 `h-32` 改为 `h-2/3`（约 2/3 屏），同步更新缓冲注释。
- 验证：历史会话发新消息，AI 流式生成时内容停在视口上部、下方留约 2/3 屏空白；生成结束缓冲收回、内容贴底。

## 5. 历史会话打开即贴底
- 改动：滚动控制器 `useChatScrollController` 增加挂载期稳定循环——挂载后用 rAF **无条件**把容器拉到底（不读 `isAtBottomRef`，避免被消息变化 effect 的 rAF 在测量未完成时误判为 false 而空转），直到 `scrollHeight` 连续多帧不变或超时收敛，收敛后写回贴底态。
- 验证：打开任一历史会话，初始滚动位置在底部（最新消息可见），而非停在中部。

## 6. 刷新历史会话不闪欢迎页
- 改动：运行时 `useChatRuntime` 的 `messages` 在 store 无该会话数据时回落到 SSR `initialMessages`（移除不再使用的 `EMPTY_MESSAGES`）。
- 验证：硬刷新一个已有会话，首屏直接显示历史消息，不再短暂闪现欢迎页。

## 7. 对话大纲摘要单行
- 改动：大纲组件 `ChatOutline` 浮层项由 `line-clamp-2` 改为 `line-clamp-1`。
- 验证：hover 大纲横线列，浮层每一轮用户原话只显示一行（超长截断）。

## 8. 思考块点击 / hover 展开 + 动效
- 改动：消息项组件 `ChatMessageItem` 思考条触发区去掉 `flex-1`（不撑满整行）、箭头移入触发区内紧跟文字；点击切换展开；hover 延迟 0.5s 展开 / 收起（避免划过误触）；点击触发区以外任意位置自动收起；展开浮层加淡入 + 下滑 + 微缩放动效。
- 验证：箭头紧贴文字；hover 停留约 0.5s 弹出思考全文、移开延迟收起；点击切换、点击外部收起；展开有过渡动效；中间空白不再误触。

## 9. 对话大纲高亮当前轮次
- 改动：消息列表 `ChatMessageList` 由虚拟项算出当前视口顶部对应的 msg index 传入；大纲组件 `ChatOutline` 映射到「当前轮次」，横线列当前项加长 + 蓝色、浮层当前项加浅蓝底色，类似 GPT 定位。
- 验证：滚动会话时，大纲对应轮次的横线高亮、hover 浮层里当前轮次项有底色，随滚动实时跟随。

## 整体验证
- `pnpm lint` 通过。
- 明 / 暗模式目测四项。
- 不破坏：输出样式（rs-xxx）、结构化块、流式增量渲染、虚拟滚动。
