# 工具栏顺序调整(推理强度移至模型旁)

## Goal

把 Chat 输入框工具栏的控件顺序调整为：**模型 推理强度 联网 指令卡 知识库 模型参数 ｜ 输出模式 输出样式**，让推理强度紧跟模型，控制项与输出项分组。

## Background

- 当前顺序（`ChatToolbar.tsx:117-305`）：模型 → 指令卡 → 联网 → 知识库 → 输出模式 → 输出样式 → 模型参数 → 推理强度。
- 推理强度在末尾、模型参数前，离模型太远；控制项与输出项混排。

## Requirements

- 目标顺序（JSX 块重排，不新增/删除控件）：
  1. 模型（`:120-155`）
  2. 推理强度 `ReasoningPicker`（`:305`）
  3. 联网 toggle（`:186-201`）
  4. 指令卡（`:160-183`）
  5. 知识库（`:204-227`）
  6. 模型参数 `ModelParamsPicker`（`:302`）
  7. 输出模式（`:230-263`）
  8. 输出样式（`:266-299`）
  - 之后是已选指令卡 chip / 附件 chip 行，不动。
- 指令卡、知识库归到「联网附近」（用户已确认），作为输入增强类与联网同组。
- 「｜」仅为逻辑分组描述，**不渲染视觉分隔条**（遵循 DESIGN.md 克制原则，不引入新 UI 元素）。
- 控件样式、行为、可见性条件（如 `cards.length > 0`、`capabilities?.reasoning`）一律不变。

## Acceptance Criteria

- [ ] 工具栏控件顺序与上述目标一致。
- [ ] 推理强度紧跟模型；输出模式/输出样式位于末尾。
- [ ] 各 picker 的展开方向、hover、选中态、清除按钮等行为不变。
- [ ] 窄屏换行（`flex-wrap`）下顺序仍正确。
- [ ] `pnpm lint && pnpm typecheck` 通过。

## Notes

- 纯 JSX 块顺序调整，无逻辑改动。改动集中在 `ChatToolbar.tsx` 的 `return` 内。
