# 合并会话与回答大纲

## Goal

消除聊天正文右侧“会话圆点大纲”与“回答标题短线大纲”并排造成的视觉重叠，统一为一个会话大纲入口；展开入口时，同时提供会话级导航和当前回答内的 Markdown 标题导航。

## Background

- 会话大纲由 `apps/web/src/features/chat/components/ChatOutline.tsx` 渲染为右侧圆点，并在展开面板中列出各轮用户消息。
- 回答大纲由 `apps/web/src/features/chat/components/ChatResponseOutline.tsx` 独立渲染为右侧短横线，并读取当前 assistant 回答中的 `h1`～`h3`。
- 两个组件同时挂载于 `apps/web/src/features/chat/components/ChatMessageList.tsx`，目前会形成两套相邻的常驻导航轨道。

## Requirements

- 右侧只保留 `ChatOutline` 的会话圆点轨道，不再独立显示回答标题短横线轨道。
- 会话大纲展开面板继续显示现有会话轮次列表。
- 当前锚定的 assistant 回答满足现有展示条件（至少 2 个 `h1`～`h3`，且回答高度至少 360px）时，展开面板在会话列表下方增加“当前回答”分区。
- “当前回答”分区按原顺序显示标题文本，并保留 `h1`～`h3` 的层级缩进。
- 点击回答标题时，继续使用现有的标题滚动定位；开启减少动态效果时不使用平滑滚动。
- 当前所在回答标题需要在展开列表中高亮。
- 没有符合条件的回答标题时，不显示“当前回答”分区，不额外占位。
- 保留现有移动端会话大纲触摸拖动行为；回答标题导航不新增移动端常驻入口。
- 复用现有组件、状态和样式，不新增依赖，不引入新的大纲抽象层。

## Out of Scope

- 不改变 Markdown 标题的渲染、生成或解析规则。
- 不改变会话锚点和轮次跳转规则。
- 不新增顶部吸附目录、回答顶部目录按钮或折叠式正文目录。
- 不调整与大纲无关的聊天布局、配色或动效。

## Acceptance Criteria

- [x] 桌面端聊天正文右侧只出现一列会话圆点，不再出现独立短横线标题轨道。
- [x] 展开会话大纲时，原有会话轮次列表仍可见且可正常跳转。
- [x] 当前回答符合条件时，同一展开面板中显示“当前回答”标题列表，标题顺序和层级正确。
- [x] 点击标题可滚动到对应位置，当前标题会随滚动更新高亮。
- [x] 当前回答不符合条件时，面板只显示会话列表。
- [x] 键盘焦点、`aria-label` 与减少动态效果行为没有退化。
- [x] 相关前端测试通过，独立复核确认未保留第二条大纲轨道。

## Technical Notes

- 这是单一聊天组件内的轻量整合，采用 PRD-only 规划。
- 最小实现方向是把现有回答标题测量与高亮逻辑并入 `ChatOutline`，然后从 `ChatMessageList` 移除独立的 `ChatResponseOutline` 挂载；不保留两套同时工作的 DOM 导航。
