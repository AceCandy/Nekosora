# 优化聊天图片附件与预览

## Goal

让用户粘贴图片后，可以直接在聊天输入框内清楚地确认、移除和打开附件；点击图片后以无边框、无表头的纯图片视图查看内容。

## Confirmed Facts

- 当前粘贴、上传、发送与移除链路已完整，不需要修改附件数据或 API。
- 当前附件状态行由 `ChatToolbar` 渲染在 `ChatInputBox` 外部；附件项只有单行文件名和很小的缩略图，没有格式与大小层级。
- 当前图片使用通用 `FilePreviewModal`，因此继承了文件名标题栏、有边框弹窗和内容背景；文本与 PDF 预览另有自身必要的信息栏。
- 参考截图及 `docs/cankao/AQBot` 都采用输入区内附件信息条；参考图片查看器不额外绘制文件标题栏或边框容器。

## In Scope

- 将现有附件/上下文状态行放入 `ChatInputBox` 的同一表面内，位于文本编辑区域上方；输入框高度随附件行自然增长。
- 将附件项改为紧凑的两行信息卡：图片保留缩略图，主行显示可截断文件名，次行显示文件格式、文件大小及必要的上传状态，右侧保留移除操作。
- 仅对 `image/*` 查看层移除文件名标题栏、弹窗边框、卡片背景和图片圆角；使用透明容器直接展示完整图片。
- 图片查看层保留可见关闭按钮、遮罩点击关闭、原生 `Escape` 关闭和可访问名称。
- 保持现有粘贴、拖放、上传、发送、移除及预览 URL 逻辑不变。
- 亮色、暗色以及 320px 起的窄屏下不得出现文字溢出、横向滚动、输入框跳动或关闭控件遮挡图片主体。

## Acceptance Criteria

- [x] 粘贴一张图片后，附件信息卡稳定出现在输入框边框内部、文本区域上方，并展示缩略图、文件名、格式、大小和移除按钮。
- [x] 长文件名在桌面与 320px 窄屏上截断，附件列表可换行且不产生页面横向滚动。
- [x] 上传中、待上传、失败与已上传状态仍可识别；已上传附件仍可点击预览，移除操作有可访问名称。
- [x] 点击图片后，查看层不包含文件名/格式/大小标题栏，不显示包裹图片的可见边框、卡片背景或图片圆角。
- [x] 图片按视口完整等比缩放；可见关闭按钮不遮挡主体，并可通过关闭按钮、遮罩和 `Escape` 退出。
- [x] 文本、PDF、音频、视频及不支持文件的现有预览结构保持不变。
- [x] 附件上传、发送和消费清理行为没有回归。

## Out of Scope

- 不修改附件上传协议、存储方式或消息 API。
- 不修改已发送消息中的图片排版。
- 不增加图片编辑、缩放工具栏、下载或轮播等新能力。
- 不移除文本/PDF 等非图片预览中的文件名、MIME、页数或其他信息栏。

## Key Decisions

- 复用现有原生 `dialog` 与 `FilePreview` 路由，不引入新的图片查看依赖。
- 图片附件使用缩略图增强识别，信息层级参考用户截图；不照搬截图中的纯文件图标。
- 图片与非图片预览按 MIME 分支处理，避免修改共享 `Modal` 的全局外观。

## Risks And Validation

- `Modal.tsx` 存在用户已有的未提交可访问性与 ESC 修复，本任务不得覆盖或回退这些改动。
- 组件无现成浏览器测试基建；需要补充静态组件回归测试，并在可登录的本地聊天页验证粘贴、窄屏、暗色和关闭路径。
