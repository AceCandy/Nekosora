# 精简分享弹窗并修复复制

## Goal

让用户在分享会话时更快完成“选择分享方式并复制链接”这一核心任务，修复复制操作缺少有效反馈的问题，同时移除不需要用户决策的输出样式设置。

## Background

- `ShareDialog` 的创建结果与已有分享列表均调用公共 `copyToClipboard`，但创建结果按钮始终显示复制图标，失败路径也完全静默，用户无法判断操作结果。
- 当前快照分享允许单独选择输出样式，实时分享显示“跟随会话”。服务端本身已支持：快照未传 `renderStyleId` 时冻结会话当前样式，实时分享读取会话当前样式。
- 数据库中的样式快照与后端兼容字段仍用于历史分享和冻结渲染，不属于本次移除范围。

## Requirements

- R1：创建结果区域和已有分享列表的复制按钮都必须复制完整分享 URL，并提供明确的成功状态。
- R2：复制失败时必须在当前弹窗内显示可感知的错误信息，不能静默失败。
- R3：分享弹窗不再展示“输出样式”字段；快照分享自动冻结创建时的会话当前样式，实时分享继续跟随会话当前样式。
- R4：保留创建/已有分享两个页签、快照/实时模式、有效期、密码保护、撤销分享等现有能力。
- R5：精简弹窗的内容密度与视觉层级，减少冗余容器和间距，但继续使用现有 `Modal`、语义字号、颜色 token、Lucide 图标及触屏目标规范。
- R6：复制按钮的成功/失败状态须兼顾图标反馈与可访问名称，弹窗在窄屏下不得横向溢出。
- R7：移除独立的弹窗标题栏与关闭按钮；创建分享与已有分享页签成为第一排。
- R8：分享模式标签与快照/实时同步分段选项同排；有效期标签与有效期控件同排；窄屏下必须保持可读且不横向溢出。
- R9：有效期使用基于现有 `Popover` 的单一触发控件，点击后可快捷选择 1 天、7 天、30 天、永久或自定义时间；选择自定义时打开原生日期时间面板，不新增下一行输入框。禁止选择已过期时间，选定后触发控件显示“截止 {date}”。
- R10：启用访问密码后，密码输入框与“设置访问密码”同排显示；未启用时不显示输入框。
- R11：点击弹窗遮罩或按 `Esc` 时请求关闭；表单相对初始值存在未提交修改时，先用确认弹窗询问是否放弃修改。成功创建分享后当前表单状态视为已保存，关闭时不再提示。

## Acceptance Criteria

- [x] AC1：点击创建结果的复制按钮后，剪贴板收到当前完整分享 URL，按钮切换为成功状态并在短暂延时后复原。
- [x] AC2：点击已有分享条目的复制按钮后，剪贴板收到对应完整分享 URL，并显示相同的成功状态。
- [x] AC3：剪贴板 API 与回退复制均失败时，弹窗显示本地化错误信息，用户能够重试。
- [x] AC4：创建页不再出现“输出样式”标签、下拉框或“跟随会话”只读字段。
- [x] AC5：创建快照分享时不显式提交 `renderStyleId`，服务端现有逻辑冻结会话当前样式；实时分享行为保持不变。
- [x] AC6：弹窗保留现有分享模式、有效期、密码、列表复制与撤销能力，布局更紧凑且 320px 宽度无横向溢出。
- [x] AC7：新增或更新针对性测试覆盖两类复制按钮的成功反馈、复制失败反馈，以及创建请求不再携带输出样式选择。
- [x] AC8：弹窗第一排仅包含创建/已有分享页签，不再显示独立标题栏或关闭按钮。
- [x] AC9：分享模式、有效期和密码设置分别采用单排布局；桌面端紧凑对齐，320px 视口无横向溢出。
- [x] AC10：点击有效期控件弹出快捷选项，可直接选择 1 天、7 天、30 天、永久或自定义；自定义日期时间控件不会额外占据一行，`min` 与提交校验均拒绝当前时间以前的值。
- [x] AC11：选定自定义时间后，有效期控件显示本地化“截止 {date}”，创建分享提交对应 ISO 时间。
- [x] AC12：勾选密码保护后，同排出现密码输入框，并继续遵守至少 8 个字符的提交约束。
- [x] AC13：针对性组件测试覆盖标题栏移除、三类单排布局、自定义时间回写/过期拒绝和密码输入展开。
- [x] AC14：默认表单点击遮罩或按 `Esc` 直接关闭；修改模式、有效期或密码后关闭会出现“放弃修改”确认；成功创建后关闭不再提示。

## Out of Scope

- 不删除或迁移后端 `renderStyleId` 输入兼容逻辑、数据库 `renderStyleSnapshot` 字段及历史分享数据。
- 不改变分享链接格式、鉴权、密码校验、有效期或撤销规则。
- 不重构聊天工具栏中的会话输出样式选择能力。

## Technical Notes

- 修改应集中在分享弹窗及其直接 props 调用链；公共剪贴板工具仅在测试证明其本身存在缺陷时才调整。
- 复用现有国际化命名空间，不在代码中写死用户可见文案。
- 本任务为轻量前端修复，采用 PRD-only 规划。
