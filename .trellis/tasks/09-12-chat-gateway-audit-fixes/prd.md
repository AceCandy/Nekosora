# Chat 与网关审查修复

用户已要求修复审查报告中的五项问题。

## 验收条件

- 模型图片由服务端下载时，拒绝解析到非公网 IP 的域名及重定向，不影响公网图片和内联图片。
- system/developer 消息中的文本块完整保留，顺序不变。
- 工具 strict 的 true/false 不再静默丢失，非法值在请求边界拒绝。
- 切换回复版本后使用目标版本的完成状态，正确显示续写入口和完成信息。
- 续写追加思考内容；没有新思考时保留旧思考，刷新前后数据一致。
- 每项缺陷都有回归验证，工作区 lint、typecheck、测试通过，独立复核完成。

不包含数据库结构调整、历史丢失内容修复、其他 UI 或路由重构。
